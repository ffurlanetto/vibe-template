Audit performance against the budgets defined in **B6** (defaults in A10).

**Absolute rule: measure before concluding.** A finding without a number is a
hypothesis, not a result — say so explicitly.

---

## 1 · Budgets
Restate the applicable budgets from B6, then state for each whether the change
respects it, breaks it, or was not measured.

| Budget | Target | Measured | Verdict |
|--------|--------|----------|---------|

## 2 · Data access anti-patterns
- [ ] No N+1 query (count the queries generated by a list endpoint)
- [ ] Indexes on frequently filtered / joined / sorted columns
- [ ] No `SELECT *` on wide tables in a hot path
- [ ] No long-running transaction holding locks
- [ ] Pagination on every collection endpoint, with a maximum page size

## 3 · I/O and concurrency
- [ ] No sequential external calls where parallel calls are possible
- [ ] Timeouts set on every outbound call
- [ ] Retries bounded, with backoff — no unbounded retry loop
- [ ] No blocking call inside an async path

## 4 · Caching
- [ ] Cacheable responses carry `Cache-Control` / `ETag`
- [ ] Cache keys include every discriminating parameter (tenant, locale, auth scope)
- [ ] Invalidation strategy documented

## 5 · Frontend (if applicable)
- [ ] Route-level bundle splitting in place
- [ ] No full re-render on partial state change
- [ ] Images optimized: format, dimensions, lazy loading
- [ ] Bundle size against the B6 budget

## 6 · Memory & payloads
- [ ] No unbounded collection loaded in memory (streaming or pagination)
- [ ] Request/response size limits enforced
